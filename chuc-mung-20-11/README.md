# Chúc mừng 44 năm Ngày Nhà giáo Việt Nam 20/11

Landing page chúc mừng kỷ niệm 44 năm Ngày Nhà giáo Việt Nam (20/11/1982 – 20/11/2026) của **Viện Chuyển đổi số và Học liệu, Đại học Huế**.

## Cấu trúc

```
index.html          Trang chính (HTML + CSS + JS thuần, không cần build)
assets/lockup.png   Cụm logo Đại học Huế – Viện Chuyển đổi số và Học liệu
assets/scene.jpg    Ảnh nền phần mở đầu
assets/thiep.jpg    Thiệp chúc mừng (dùng cho nút tải về và ảnh chia sẻ)
```

## Triển khai

- **GitHub Pages:** Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`.
- **Vercel:** Import repo, Framework Preset: `Other`, không cần lệnh build.
